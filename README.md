---

## 🚀 Uso Rápido via cURL

```bash
# Retorna apenas o IP em texto puro
curl https://ponte.ozpro.com.br/api/ip?format=text

# Retorna dados geográficos e de dispositivo completos em JSON
curl https://ponte.ozpro.com.br/api/meu-ip
```
